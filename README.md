# MiniKids

## Instalación recomendada

1. Crea un proyecto vacío:
   npx create-expo-app@latest MiniKids --template blank

2. Copia estos archivos dentro del proyecto.

3. Instala las dependencias compatibles con tu versión de Expo:
   npm install @react-navigation/native @react-navigation/native-stack @react-native-async-storage/async-storage
   npx expo install react-native-screens react-native-safe-area-context react-native-svg expo-av

4. Ejecuta:
   npx expo start

Los archivos WAV de assets/audio son provisionales. Puedes reemplazarlos manteniendo los mismos nombres o actualizar gameData.js.
